# 📦 eGain Chatbot – Track a Lost Package

A smart and interactive chatbot that helps users track lost packages, receive updates, or file a claim. Built for the eGain Intern Take-Home Assignment.

## 💡 Features
- Command-line chatbot (Python)
- Web-based chatbot (HTML/CSS/JS)
- Handles invalid tracking numbers and user inputs
- Supports email updates, human agent connection, and claim filing
- Simulated delivery updates
- Dark/light mode toggle and animated typing

## 📂 Files Included
- `chatbot.py` — Command-line version
- `index.html`, `style.css`, `script.js` — Web version
- `slides.pdf` — Presentation deck

### 🔧 Python CLI
